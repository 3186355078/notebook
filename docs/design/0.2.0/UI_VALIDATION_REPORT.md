## 设计系统

- 统一间距：4 / 8 / 12 / 16 / 24 / 32 dp。
- 统一圆角：小控件 10 dp、输入 12 dp、卡片 16 dp、Sheet 顶部 24 dp。
- Material 3 Typography 统一承担标题、正文、标签和辅助信息。
- Android 12+ 默认使用 Dynamic Color；旧系统使用低饱和青蓝品牌回退色。
- 优先级同时使用文本、图形和语义色，不依赖颜色单独表达。
- 普通动效限制在 150～300 ms，不使用无限或强制弹跳动画。

## Todo 交互

- 快速添加默认中优先级、未开始状态；空标题不会创建。
- 完成动作必须经过“仅完成 / 完成并记录 / 取消”选择。
- 编辑器将状态改为 DONE 时仍进入显式完成选择，不绕过同步确认。
- 拖动只修改 UI 临时顺序，结束后一次性持久化；跨优先级边界同步更新 priority。
- TalkBack 提供上移、下移、提高优先级和降低优先级替代操作。
- 完成/取消项可折叠；折叠状态不进入 Room 或备份。

## 隐私与错误状态

- 页面明确提示待办只保存在本地；同步为工作记录后才可能参与 AI 总结。
- Snackbar 与错误状态不显示 Todo 正文、绝对路径、SAF URI 或内部异常。
- 完整备份未加密和 API Key 不在备份中的提示继续保留。

## 真机结果

- 设备：HONOR PPG-AN00，Android 16 / API 36；不记录设备序列号。
- 自动化：51/51 个 Instrumentation/Compose 方法通过，failures/errors/skipped 均为 0；其中阶段 10 新增 Today Todo 方法 10 个。
- 规模：50 条 Todo 在受限高度 LazyColumn 中滚动，最后一项可达；设备级 v2 备份写入、预检并恢复 50 条 Todo，内容块链接保持。
- 主题与尺寸：浅色、深色、Dynamic Color 路径、1.5× 字体和横屏均检查。横屏的紧凑垂直视口需要滚动，这是预期布局，不会遮挡或丢失主要操作。
- 回归发现并修复：原浮动快速记录按钮会覆盖表格底部“添加一列”操作；现改为列表内紧凑工具栏，目标真机用例和完整 51 项回归均通过。
